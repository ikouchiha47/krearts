# Comic Book Text Overlay Styles

## Style 1: In-Panel Caption Boxes (RECOMMENDED)
**What it is**: Caption boxes overlaid on the bottom of each panel
**Best for**: Narration, scene setting, internal monologue
**Appearance**:
```
┌─────────────────────────┐
│                         │
│   [Panel Image]         │
│                         │
│  ┌──────────────────┐   │
│  │ Caption text...  │   │
│  └──────────────────┘   │
└─────────────────────────┘
```
**Pros**: 
- Classic comic book style
- Doesn't add extra height
- Integrated with artwork
**Cons**: 
- Covers small part of image
- Need to position carefully

## Style 2: Below-Page Caption Bar (CURRENT)
**What it is**: Text bar below entire page
**Best for**: Page-level narration
**Appearance**:
```
┌─────────────────────────┐
│   [Full Page Image]     │
│   [Multiple Panels]     │
└─────────────────────────┘
┌─────────────────────────┐
│ Caption text...         │
└─────────────────────────┘
```
**Pros**: 
- Doesn't cover artwork
- Easy to read
**Cons**: 
- Adds extra height
- Not traditional comic style
- Feels disconnected

## Style 3: Speech Bubbles (CLASSIC)
**What it is**: Rounded bubbles with tails pointing to speaker
**Best for**: Dialogue
**Appearance**:
```
┌─────────────────────────┐
│     ╭─────────╮         │
│     │ Hello!  │         │
│     ╰────┬────╯         │
│          │              │
│        [👤]             │
└─────────────────────────┘
```
**Pros**: 
- Most traditional
- Shows who's speaking
- Dynamic placement
**Cons**: 
- Complex to position
- Requires tail drawing
- Can clutter panels

## Style 4: Thought Bubbles
**What it is**: Cloud-like bubbles for internal thoughts
**Best for**: Character thoughts, internal monologue
**Appearance**:
```
┌─────────────────────────┐
│    ☁️─────────☁️         │
│   ☁️ Thinking... ☁️      │
│    ☁️─────────☁️         │
│       ○ ○ ○             │
│        [👤]             │
└─────────────────────────┘
```

## Style 5: Top Banner Caption
**What it is**: Caption at top of panel
**Best for**: Time/place stamps, scene transitions
**Appearance**:
```
┌─────────────────────────┐
│ ┌──────────────────┐    │
│ │ LATER THAT DAY   │    │
│ └──────────────────┘    │
│                         │
│   [Panel Image]         │
└─────────────────────────┘
```

## Style 6: Side Caption
**What it is**: Vertical text along panel edge
**Best for**: Timestamps, location labels
**Appearance**:
```
┌─┬───────────────────────┐
│T│                       │
│I│   [Panel Image]       │
│M│                       │
│E│                       │
└─┴───────────────────────┘
```

## Style 7: Borderless Text
**What it is**: Text directly on image, no box
**Best for**: Sound effects, emphasis
**Appearance**:
```
┌─────────────────────────┐
│                         │
│   BOOM!  [Panel Image]  │
│                         │
└─────────────────────────┘
```

## Recommended: Style 1 (In-Panel Captions)

Based on your reference image, **Style 1** is what you want:
- Caption boxes at the **bottom of each panel**
- Overlaid on the image (not below it)
- White background, black text, black border
- Positioned in the lower portion of each panel
- Doesn't add extra height to the page

This is the most common style in modern comics and matches your reference exactly.
