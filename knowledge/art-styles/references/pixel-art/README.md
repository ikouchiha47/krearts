# STYLE: Pixel Art (16-bit Retro)

## Overview
Retro video game aesthetic inspired by 16-bit era consoles (SNES, Genesis). Deliberate pixelation, limited color palettes, dithering techniques, and nostalgic game UI elements. Perfect for gaming-themed comics or retro aesthetics.

## Defining Characteristics
- **Line Work**: Visible pixels as deliberate aesthetic, no anti-aliasing
- **Anatomy**: Sprite-based character design, readable at small sizes
- **Expressions**: Expressive despite pixel limitations
- **Panel Density**: 4-6 panels per page, mimicking game screen compositions
- **Colors**: Limited palette (16-64 colors), dithering for shading
- **Composition**: Game screen layouts with UI integration

## Panel Layout
- **Typical**: 4-6 panels mimicking game screens
- **Dialogue Heavy**: RPG-style text boxes at bottom with character portraits
- **Action Scenes**: Side-scrolling combat, turn-based battle screens
- **Establishing Shots**: World map overview, top-down town/dungeon
- **Detail Panels**: Item/inventory close-ups, status screen layouts

- Bold color blocks for recognition

Retro video game aesthetic inspired by 16-bit era consoles (SNES, Genesis). Deliberate pixelation, limited color palettes, dithering techniques, and nostalgic game UI elements. Perfect for gaming-themed comics or retro aesthetics.

## 1. Style Identity

### Summary

### Mood & Tone
- Nostalgic
- Playful
- Game-like
- Retro-futuristic

### Panel Density
4-6 panels per page, mimicking game screen compositions

## 2. Linework & Rendering Rules

### Resolution
- Visible pixels as deliberate aesthetic
- Consistent pixel density throughout
- No anti-aliasing (keep edges sharp)
- Readable at small sizes

### Colors
- Limited palette (16-64 colors typically)
- No smooth gradients
- Flat color regions
- High contrast for readability

### Shading
- Dithering patterns instead of gradients
- Checkerboard transitions
- Limited shade steps (3-4 per color)
- No soft blending

### Texture
- Pixel-perfect patterns
- Tile-based backgrounds
- Consistent pixel grid
- No sub-pixel rendering

### Avoid
- Anti-aliasing
- Smooth gradients
- High color counts
- Photorealistic detail
- Modern HD resolution

- Curved screen edges

- 50% checkerboard for mid-tones
- 25%/75% for lighter/darker
- Ordered dithering for gradients
- Pattern consistency throughout

## 8. Sound Effects & Onomatopoeia

### Classic Game Sounds (Visual)
- `BLEEP` - Menu selection
- `BLIP BLIP` - Text appearing
- `DING` - Item acquired
- `WHOOSH` - Attack swing
- `CRASH` - Impact

### Battle Sounds
- `SLASH` - Sword attack
- `POW` - Physical hit
- `FWOOSH` - Magic spell
- `MISS` - Attack missed
- `CRITICAL!` - Critical hit text

### RPG Text Conventions
- `[Character]: Dialogue...`
- `You obtained [ITEM]!`
- `[Enemy] attacks!`
- `Level Up!`
- `Game Over`

### Lettering Style
- Pixel fonts in text boxes
- 8-bit style for sound effects
- System font, all caps
- Pop-up damage numbers
- Status effect icons + text

## 9. Visual Effect Conventions

### Pixel Techniques
- **Dithering**: Checkerboard for gradients
- **Sprite Flash**: White flash on damage
- **Screen Shake**: Impact emphasis (implied)
- **Particle Pixels**: Explosions, magic, sparkles
- **Palette Swap**: Color variations for enemies

### UI Elements
- **Health Bars**: Segmented or continuous
- **Mana/MP**: Different color from HP
- **Dialogue Boxes**: Bottom screen, bordered
- **Inventory Grids**: Item slot arrays
- **Mini Maps**: Corner placement
- **Status Icons**: Buff/debuff indicators

### Animation Implications
- Key frames suggest motion
- Smear frames as pixel trails
- Impact frames with flash
- Idle animation loops implied

## 10. Technical Constraints (For Authenticity)

- Limit to 16-256 colors per scene
- Use dithering instead of gradients
- Keep sprites readable at small sizes
- Maintain consistent pixel density
- Avoid anti-aliasing (sharp edges)
- Use tile-based backgrounds
- Respect platform limitations for authenticity
