# Genre Expansion Guide

## Overview

This guide explains how to adapt the Cinema storyline generation system from detective-specific to genre-agnostic storytelling.

---

## Current System (Detective-Specific)

**Fixed Elements**:
- Roles: killer, victim, accomplice, witness, detective, framed_suspect
- Conflict Type: Investigation (detective uncovers truth)
- Evidence System: Clues, forensics, alibis
- Resolution: Reveal who committed crime and why

**Strengths**:
- Deep character psychology
- World context integration
- Evidence-based logic
- Fair-play mystery principles

**Limitation**: Only works for detective/mystery stories

---

## Universal Story Framework

### Core Components (Genre-Agnostic)

1. **Protagonist(s)**: Character(s) driving the story
2. **Antagonist(s)**: Force(s) opposing protagonist
3. **Conflict Type**: What they're fighting over/about
4. **Stakes**: What happens if protagonist fails
5. **Resolution Pattern**: How conflicts typically resolve in this genre

### Genre-Specific Patterns

Each genre has typical:
- **Character archetypes** (hero, mentor, rival, etc.)
- **Conflict patterns** (man vs man, man vs self, man vs society)
- **Plot beats** (call to adventure, training montage, final battle)
- **Thematic concerns** (power, identity, justice, love, survival)

## Genre Catalog

### 1. Action/Adventure

**Protagonist**: Hero with physical/mental skills
**Antagonist**: Villain with opposing goal
**Conflict**: Physical confrontation, chase, rescue
**Stakes**: Lives, treasure, world safety
**Resolution**: Climactic battle, hero wins through skill/growth

**Character Roles**:
- hero: Main protagonist
- mentor: Guides hero
- sidekick: Supports hero
- villain: Main antagonist
- henchman: Villain's subordinates
- innocent: Person to protect/rescue

**Plot Beats** (Hero's Journey):
1. Ordinary World
2. Call to Adventure
3. Refusal of Call
4. Meeting Mentor
5. Crossing Threshold
6. Tests, Allies, Enemies
7. Approach to Inmost Cave
8. Ordeal
9. Reward
10. Road Back
11. Resurrection
12. Return with Elixir

**Examples**: Indiana Jones, Die Hard, Mad Max

---

### 2. Shonen Battle (Anime/Manga)

**Protagonist**: Young hero with hidden potential
**Antagonist**: Increasingly powerful enemies
**Conflict**: Physical/magical battles, tournaments
**Stakes**: Friends, world, self-improvement
**Resolution**: Power-up → victory, but new threat emerges

**Character Roles**:
- protagonist: Main hero (underdog)
- rival: Equal/superior fighter who pushes protagonist
- mentor: Teaches techniques
- team: Friends/allies with complementary powers
- arc_villain: Current major threat
- final_boss: Ultimate antagonist

**Plot Beats** (Shonen Formula):
1. Protagonist weak/inexperienced
2. Inciting incident (attack, tournament, challenge)
3. Training arc (gain new power)
4. Minor battles (test new power)
5. Major battle (vs arc villain)
6. Defeat/setback
7. Power-up/revelation
8. Victory
9. New threat appears
10. Repeat cycle

**Power System Requirements**:
- Clear rules for abilities
- Progression path (training, experience, revelation)
- Weaknesses/limitations
- Creative applications

**Examples**: Bleach, Naruto, Dragon Ball, My Hero Academia

---

### 3. Cyberpunk/Sci-Fi

**Protagonist**: Outsider/rebel in dystopian system
**Antagonist**: Oppressive system/corporation/AI
**Conflict**: Individual vs technology/society
**Stakes**: Humanity, freedom, identity
**Resolution**: Pyrrhic victory, system exposed but not destroyed

**Character Roles**:
- hacker: Tech-savvy rebel
- corpo: Corporate antagonist
- street_kid: Survivor from lower class
- netrunner: Digital world specialist
- fixer: Connection broker
- ripperdoc: Cybernetic surgeon

**Plot Beats** (Cyberpunk Formula):
1. Protagonist in low position
2. Job/heist opportunity
3. Things go wrong
4. Conspiracy revealed
5. Protagonist hunted
6. Gather allies/resources
7. Infiltrate system
8. Expose truth
9. Ambiguous victory

**World Requirements**:
- Technology level (cybernetics, AI, VR)
- Class divide (rich vs poor)
- Corporate control
- Underground culture

**Examples**: Akira, Blade Runner, Cyberpunk 2077, Ghost in the Shell

---

### 4. Character Drama (Arcane-style)

**Protagonist**: Multiple characters with conflicting goals
**Antagonist**: Other protagonists, society, fate
**Conflict**: Internal (identity, morality) + External (relationships, class)
**Stakes**: Relationships, identity, moral integrity
**Resolution**: Tragedy, bittersweet, transformation

**Character Roles**:
- protagonist_a: One side of conflict
- protagonist_b: Other side of conflict
- catalyst: Character whose actions force conflict
- victim: Character hurt by conflict
- mediator: Tries to bridge divide (often fails)

**Plot Beats** (Tragedy Formula):
1. Establish relationships (happy/functional)
2. Inciting incident (trauma, betrayal, accident)
3. Characters diverge (different responses)
4. Escalating conflict
5. Point of no return
6. Climactic confrontation
7. Tragic resolution
8. Aftermath (changed forever)

**Thematic Requirements**:
- Moral ambiguity (no clear right/wrong)
- Systemic issues (class, power, prejudice)
- Personal vs political
- Cost of choices

**Examples**: Arcane, Breaking Bad, The Wire, Attack on Titan (later arcs)

---

### 5. Western

**Protagonist**: Lone gunslinger/lawman
**Antagonist**: Outlaws, corrupt officials, nature
**Conflict**: Law vs chaos, civilization vs wilderness
**Stakes**: Town safety, personal honor, survival
**Resolution**: Showdown, protagonist leaves/dies

**Character Roles**:
- gunslinger: Skilled fighter with code
- sheriff: Lawman (may be corrupt)
- outlaw: Criminal antagonist
- settler: Innocent townsperson
- native: Indigenous character (handle respectfully)
- saloon_owner: Information broker

**Plot Beats** (Western Formula):
1. Stranger arrives in town
2. Town has problem (outlaws, corruption)
3. Protagonist reluctant to help
4. Personal stake emerges
5. Gather allies (or work alone)
6. Confrontation with antagonist
7. Showdown (gunfight)
8. Protagonist leaves/dies

**World Requirements**:
- Frontier setting (lawless, harsh)
- Code of honor
- Violence as solution
- Isolation

**Examples**: Blueberry, The Good/Bad/Ugly, Unforgiven, Django

---

### 6. Romance

**Protagonist**: Two people (or love triangle)
**Antagonist**: Circumstances, misunderstanding, rival
**Conflict**: Obstacles to relationship
**Stakes**: Happiness, fulfillment, identity
**Resolution**: Together, apart, or bittersweet

**Character Roles**:
- love_interest_a: First romantic lead
- love_interest_b: Second romantic lead
- rival: Competing for affection
- obstacle: Person/thing preventing relationship
- confidant: Friend who gives advice

**Plot Beats** (Romance Formula):
1. Meet cute (first encounter)
2. Attraction/tension
3. Obstacle emerges
4. Relationship develops
5. Misunderstanding/conflict
6. Separation
7. Grand gesture
8. Resolution (together or apart)

**Examples**: Pride and Prejudice, Your Name, Eternal Sunshine

---

### 7. Horror

**Protagonist**: Survivor(s)
**Antagonist**: Monster, killer, supernatural force
**Conflict**: Survival, escape
**Stakes**: Life, sanity, soul
**Resolution**: Escape (often with losses), defeat monster, or death

**Character Roles**:
- final_girl: Main survivor
- monster: Threat
- skeptic: Doesn't believe until too late
- believer: Knows the danger
- sacrifice: Dies to save others
- first_victim: Dies early to establish threat

**Plot Beats** (Horror Formula):
1. Normal world
2. First sign of threat (ignored)
3. Threat escalates
4. Characters realize danger
5. Attempt to fight/escape
6. Deaths/setbacks
7. Final confrontation
8. Survival or death

**Examples**: Alien, The Thing, Hereditary

## Implementation Strategy

### Phase 1: Add Genre Templates

Create files in `knowledge/storywriting/genres/`:
- `action-adventure.md`
- `shonen-battle.md`
- `cyberpunk.md`
- `character-drama.md`
- `western.md`
- `romance.md`
- `horror.md`

Each file contains:
- Character role definitions
- Plot beat templates
- Conflict patterns
- Thematic concerns
- World-building requirements
- Examples

### Phase 2: Modify Plotbuilder Task

Update `cinema/agents/bookwriter/plotbuilder/tasks.yaml`:

```yaml
plotbuilder:
  generic:
    description: |
      Given this plot structure and genre:
      
      ## Genre
      {genre}
      
      ## User Requirements
      {user_requirements}
      
      ## Character Roles (Genre-Specific)
      {character_roles}
      
      ## Plot Beats (Genre-Specific)
      {plot_beats}
      
      Your task is to:
      - Generate character personas matching genre archetypes
      - Build relationships that serve genre conflicts
      - Create plotline following genre conventions
      - Apply appropriate world context
      
      ## Tool Usage
      - Use DirectoryReadTool to explore knowledge/storywriting/genres/
      - Use FileReadTool to read genre-specific templates
      - Use knowledge/narrative-structures/ for timeline organization
      
      ## Output Format
      [Same as detective format, but with genre-appropriate roles]
```

### Phase 3: Update Models

Modify `cinema/models/storyline.py`:

```python
class CharacterDetail(BaseModel):
    name: str
    role: str  # Now accepts ANY role, not just detective roles
    archetype: str  # Genre-specific archetype (hero, rival, mentor, etc.)
    # ... rest of fields
```

### Phase 4: Create Genre Router

Add logic to select appropriate template:

```python
def get_genre_template(genre: str) -> dict:
    """Load genre-specific template"""
    genre_map = {
        "detective": "detective/principles.md",
        "action": "genres/action-adventure.md",
        "shonen": "genres/shonen-battle.md",
        "cyberpunk": "genres/cyberpunk.md",
        # ...
    }
    return load_template(genre_map[genre])
```

## Migration Path

### Keep Detective System

Don't remove detective-specific logic. Instead:

1. **Create generic base class**:
   - Universal character/world/plot models
   - Genre-agnostic validation

2. **Detective as specialization**:
   - Inherits from generic base
   - Adds detective-specific validation (evidence, clues, alibis)

3. **Add other genres as specializations**:
   - Each genre inherits from base
   - Adds genre-specific validation

### Example Structure

```
StorylineGenerator (base)
├── DetectiveStorylineGenerator
│   ├── Evidence validation
│   ├── Alibi checking
│   └── Clue distribution
├── ActionStorylineGenerator
│   ├── Power scaling
│   ├── Battle choreography
│   └── Hero's journey beats
├── CyberpunkStorylineGenerator
│   ├── Tech consistency
│   ├── Class conflict
│   └── Dystopian world-building
└── RomanceStorylineGenerator
    ├── Relationship dynamics
    ├── Obstacle plausibility
    └── Emotional beats
```

## Key Insight

Your detective system is already 80% of the way there. The core components (character depth, world context, relationship graphs, narrative structures) are universal. You just need to:

1. **Swap out** detective-specific roles/conflicts
2. **Add** genre-specific templates
3. **Keep** the deep character psychology and world-building

The quality of your detective stories comes from character depth and world integration, not from being detective-specific. That same depth will make ANY genre compelling.
